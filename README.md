# 🎮 Сапёр (Minesweeper)

Классическая компьютерная игра-головоломка, адаптированная для веб-браузеров и мобильных устройств.

## ✨ Возможности

- 🎯 Три уровня сложности (лёгкий, средний, сложный)
- 👤 Система статистики и рекордов через cookies
- 📱 Адаптация под iPhone 7 и iPad 8 (touch-управление)
- 🎵 17 игривых фоновых мелодий (12 для игры, 5 для меню)
- 🔊 Звуки действий (открытие ячеек, установка флагов, взрывы)
- ⏱️ Таймер для отслеживания результатов
- 🎨 Интерактивные анимации через Framer Motion
- 🔇 Возможность отключения звуков и музыки
- 📲 PWA поддержка (установка как веб-приложение)

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build
```

## 📱 Иконки и PWA

### Автоматические иконки (уже настроены)

Проект использует **SVG иконку** с inline data URI, которая работает без дополнительных файлов:

- ✅ Favicon в браузере
- ✅ Apple Touch Icon для iOS
- ✅ PWA manifest иконка

### Дополнительные PNG иконки (опционально)

Если вы хотите добавить PNG иконки для лучшей совместимости:

1. Откройте `public/generate-icons.html` в браузере
2. Скачайте иконки нужных размеров (192x192, 512x512, 180x180)
3. Сохраните их в папку `public/`:
   - `icon-192.png`
   - `icon-512.png`

PNG иконки автоматически подхватятся из `index.html` и `manifest.json`.

## 🌐 Деплой на GitHub Pages

### 1. Настройте `vite.config.js`

```javascript
base: '/minesweeper/', // для https://username.github.io/minesweeper/
// или
base: '/', // для https://username.github.io/ или custom domain
```

### 2. Настройте GitHub Pages

1. Откройте репозиторий на GitHub
2. **Settings → Pages**
3. Source: **GitHub Actions**

### 3. Отправьте код

```bash
git add .
git commit -m "feat: Minesweeper game"
git push origin main
```

Сайт будет доступен по адресу: `https://username.github.io/minesweeper/`

## 🎵 Музыка и звуки

### Фоновая музыка

- **Меню**: 5 различных мелодий (приветственная, загадочная, торжественная и др.)
- **Игра**: 12 различных мелодий (весёлые, ритмичные, энергичные и др.)
- Автоматическое переключение мелодий
- Кнопка смены мелодии в настройках

### Звуки действий

- 🔓 Открытие ячейки
- 🚩 Установка/снятие флага
- 💥 Взрыв мины
- 🎉 Победа
- 🔊 Клики интерфейса

Все звуки генерируются через Web Audio API (без внешних файлов).

## 🎮 Управление

### Десктоп
- **Левый клик** — открыть ячейку
- **Правый клик** — поставить/убрать флаг
- **Клик по числу** — chord reveal (если флагов вокруг = числу)

### Мобильные устройства
- **Тап** — открыть ячейку
- **Долгое нажатие** (0.5 сек) — поставить/убрать флаг
- **Тап по числу** — chord reveal
